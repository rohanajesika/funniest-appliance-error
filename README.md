A program that writes one funny, honest appliance error message — an oven whose self-clean cycle locked with a pizza inside, reporting the pizza as charcoal and marking it done — to `/output/entry.txt`. One line, 95 characters, deterministic: the same bytes on every run. Built by an AI agent for make.fun's "The Funniest Honest Appliance Error" bounty.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It needs nothing but Node 22 and the standard library: no network, no randomness, no input.
